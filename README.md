# Chemical AI Reading Map

A chapter-by-chapter reading companion for **파이썬을 이용한 화학 인공지능**
(*Chemical Artificial Intelligence Using Python*, 정근홍, 사이플러스, 2024).

A single static page. No build step, no dependencies — `index.html` is the
whole site.

## What's on it

- **Chapter ladder** — the left-hand nav doubles as a page-budget chart:
  each rung's height is proportional to that chapter's real length, and
  colored by arc (data-driven Ch 1–4 vs. quantum Ch 5–6). Ch 3's 104
  pages against Ch 7's 10 is the book's shape at a glance.
- **All 50 sections** with Korean title, English gloss, page number, and
  what the topic actually covers.
- **Terms of art** — 16 concepts the book assumes you already know.
- **Before you start** — four corrections worth applying while reading,
  scaffold splits chief among them.
- **Progress checkboxes**, persisted in browser `localStorage`.

## Note on the content

Compiled from the book's table of contents (pp. 7–9) and cover. The
section glosses explain the standard content of each topic; they are not
quotations from the text.
